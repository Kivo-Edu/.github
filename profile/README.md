Kivo turns a textbook chapter into learning games. A teacher uploads the lesson, Kivo builds games from it in Arabic or English, and the class plays them.

<p dir="rtl">ارفع فصلاً من الكتاب المدرسي، وكيفو يحوّله إلى ألعاب تعليمية بالعربية أو الإنجليزية.</p>

### How it works

1. **Upload a chapter.** A PDF, a Word file or photos of the pages.
2. **Kivo builds the games.** Every question becomes something to play. The answer is the lane you run into, the one you slice, the jar you drop it in. No pop-up quizzes.
3. **The class plays.** Each student on their own, or the whole class together on the class screen, and the teacher sees the progress.

### The games

| Game | How you answer |
| --- | --- |
| **Lane Runner** · عدّاء المسارات | Run into the lane with the right answer. |
| **Answer Slicer** · قطّاع الأجوبة | Slice the right answer and let the wrong ones fall. |
| **Bubble Shooter** · مدفع الفقاعات | Fire each item at its group. |
| **Answer Catcher** · صيّاد الإجابات | Catch what belongs in the basket. |
| **Rhythm Tiles** · بلاطات الإيقاع | Tap true or false on the beat. |
| **Souq Sort** · مرطبانات السوق | Drop each item into the jar of its era. |
| **Arena .io** · ساحة io | Eat the right answers and grow. |
| **Class Boss Raid** · غزوة الصف | The whole class, live. Every right answer from any phone hits the monster. |
